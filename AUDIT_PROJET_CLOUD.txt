  MODULE AUTHENTIFICATION (Backend Spring Boot)
══════════════════════════════════════════════════════════

1. ✅ Inscription utilisateur (email/mot de passe)
   ─ Backend : AuthController.signup() → POST /api/auth/signup
   ─ AuthService.signup() crée un Utilisateur avec email, nom, mot de passe hashé (BCrypt), rôle UTILISATEUR
   ─ Frontend : RegisterPage.tsx avec formulaire complet (nom, email, mot de passe)
   ─ Fichiers : AuthController.java, AuthService.java, RegisterPage.tsx

2. ✅ Authentification utilisateur (email/mot de passe)
   ─ Backend : AuthController.login() → POST /api/auth/login
   ─ AuthService.login() vérifie les identifiants, renvoie un JWT + date d'expiration
   ─ Frontend : LoginPage.tsx avec formulaire, AuthContext.tsx gère le state global
   ─ JWT généré via JwtService (HMAC-SHA256), stocké en localStorage
   ─ Fichiers : AuthController.java, AuthService.java, JwtService.java, LoginPage.tsx, AuthContext.tsx

3. ⚠️ Modification des informations utilisateur — PARTIELLEMENT
   ─ Backend : UtilisateurController.updateMe() → PUT /api/utilisateurs/me
   ─ UtilisateurService.updateMe() permet de modifier nom complet et mot de passe
   ─ Frontend : UserProfilePage.tsx avec formulaire (nom, changement mot de passe avec confirmation)
   ─ ⚠️ PROBLÈME : La page UserProfilePage.tsx existe mais N'EST PAS enregistrée dans les routes de App.tsx
   ─ → La page est inaccessible en navigation, aucun lien n'y mène
   ─ Fichiers : UtilisateurController.java, UtilisateurService.java, UserProfilePage.tsx

4. ✅ Gestion de session avec durée configurable
   ─ Backend : AuthSession entity (table session_utilisateur) stocke token + date_expiration
   ─ Durée configurable via AppConfig (clé "session.duration.minutes", défaut 30)
   ─ JwtService.issueTokenWithDuration() utilise la durée configurée
   ─ AppConfigController permet au MANAGER de modifier la durée via API PUT /api/config/{key}
   ─ Frontend : ManagerPage.tsx affiche et permet la modification de la configuration
   ─ Fichiers : AuthSession.java, AppConfigService.java, AppConfigController.java, JwtService.java

5. ✅ Sécurité : Limite de tentatives (3 par défaut, configurable), blocage auto, API REST de déblocage
   ─ Backend : AuthService.login() compte les tentatives échouées
   ─ Limite configurable via AppConfig (clé "auth.max.login.attempts", défaut 3)
   ─ Blocage automatique quand tentatives >= max → estBloque = true + sync Firestore
   ─ API de déblocage : AuthController.unlock() → POST /api/auth/unlock (réservé MANAGER)
   ─ AuthService.unlockUser() remet tentatives à 0, estBloque à false, synchronise Firestore
   ─ Frontend : LockedUsersPage.tsx + UtilisateursPage.tsx + ManagerPage.tsx (formulaire déblocage)
   ─ Fichiers : AuthService.java, AuthController.java, LockedUsersPage.tsx, UtilisateursPage.tsx

6. ✅ Documentation API Swagger
   ─ Dépendance springdoc-openapi-starter-webmvc-ui dans pom.xml
   ─ Configuration : springdoc.swagger-ui.path=/swagger-ui.html
   ─ Accessible à http://localhost:8080/swagger-ui.html
   ─ Fichiers : pom.xml, application.properties
