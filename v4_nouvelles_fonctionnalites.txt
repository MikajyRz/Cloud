
Projet Cloud S5 - Version 4 (V4 du 10 février 2026)
Nouvelles fonctionnalités et modifications par rapport aux versions précédentes

---

### **Objectifs principaux**
- Mise en place d'un **fournisseur d'identité** (Identity Provider) dans un environnement Docker parmi les options suivantes :
  - PHP MVC (sans FlightPHP)
  - Java
  - .NET
  - Node.js
- **API uniquement** (pas d'interface graphique)

---

### **Module Authentification**
- **Durée de vie des sessions** configurable
- **Limite de tentatives de connexion** :
  - Paramétrable (3 tentatives par défaut)
  - Blocage automatique du compte après dépassement
- **Réinitialisation du blocage** via une API REST dédiée
- **Documentation API** générée avec Swagger

---

### **Module Cartes (Nouveau)**
- **Serveur de cartes hors ligne** déployé dans Docker
- **Téléchargement de la ville d'Antananarivo** (rues et infrastructures)
- **Intégration de Leaflet** pour l'affichage et la manipulation des cartes dans l'application web

---

### **Module Web (Évolutions)**
#### **Général**
- Utilisation de l'**API REST Authentification** pour :
  - La connexion des utilisateurs
  - La création de comptes (uniquement pour le manager)
- **Deux profils utilisateurs** :
  - Visiteur (accès sans compte)
  - Manager (compte créé par défaut)

#### **Fonctionnalités Manager (Nouveautés)**
- **Catégorisation des réparations** :
  - Niveaux de 1 à 10 (définis dans le backoffice)
  - **Calcul automatique du budget** :
    `budget = prix_par_m2 (forfaitaire) × niveau × surface_m2`
- **Gestion de l'avancement** :
  - Nouveau : 0%
  - En cours : 50%
  - Terminé : 100%
  - **Enregistrement des dates** pour chaque étape
- **Tableau de statistiques** :
  - Délai moyen de traitement des travaux
