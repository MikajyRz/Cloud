FONCTIONNALITÉS PAR MODULE
==================================================

MODULE AUTHENTIFICATION
------------------------------

1. Inscription des utilisateurs (email/mot de passe)
2. Authentification des utilisateurs (email/mot de passe)
3. Modification des informations utilisateur
4. Gestion des sessions:
   - Durée de vie paramétrable
5. Sécurité:
   - Limite de tentatives de connexion (3 par défaut, paramétrable)
   - Blocage automatique après dépassement
   - API REST pour réinitialiser le blocage
6. Documentation API via Swagger


MODULE CARTES
------------------------------

1. Serveur de cartes hors ligne dans Docker
2. Données géographiques:
   - Téléchargement de la ville d'Antananarivo avec les rues
3. Fonctionnalités:
   - Affichage avec Leaflet
   - Manipulation de la carte (zoom, déplacement)


MODULE WEB
------------------------------

PROFILS:
1. Visiteur (sans authentification):
   - Visualisation de la carte avec les points de problèmes routiers
   - Affichage des informations au survol:
     * Date du problème
     * Statut (nouveau/en cours/terminé)
     * Surface en m²
     * Budget
     * Entreprise concernée
     * Lien vers les photos
   - Tableau de récapitulation:
     * Nombre de points
     * Surface totale
     * Avancement en %
     * Budget total

2. Manager (avec authentification):
   - Création de comptes utilisateurs
   - Synchronisation:
     * Récupération des signalements Firebase
     * Envoi des données vers Firebase pour mobile
     * Synchronisation des comptes mobiles créés
   - Gestion des utilisateurs:
     * Débloquer les comptes bloqués
   - Gestion des signalements:
     * Modification des informations (surface, budget, entreprise)
     * Changement de statut
     * Spécification des dates pour chaque étape
   - Statistiques:
     * Calcul d'avancement (nouveau=0%, en cours=50%, terminé=100%)
     * Tableau des délais moyens de traitement


MODULE MOBILE
------------------------------

1. Authentification:
   - Connexion via Firebase (inscription via manager web uniquement)
2. Signalement des problèmes:
   - Localisation sur carte (Leaflet + OpenStreetMap)
   - Ajout de photos (1 ou plusieurs)
   - Inputs: titre, description, image
   - Les autres informations (surface, budget, entreprise) sont mises à jour par le manager depuis le web
3. Visualisation:
   - Affichage de la carte avec les problèmes
   - Tableau récapitulatif (identique au web)
   - Filtre "Mes signalements uniquement"
4. Notifications:
   - Réception à chaque changement de statut des signalements personnels


EXIGENCES TECHNIQUES
------------------------------

1. Technologies:
   - Web: React/Angular/VueJS (au choix, différent du mobile)
   - Mobile: Ionic avec React/Angular/VueJS (au choix, différent du web)
   - Base de données: PostgreSQL (Docker)
2. Livrables:
   - Code source (GitHub/GitLab public)
   - Documentation technique:
     * MCD (Modèle Conceptuel de Données)
     * Scénarios d'utilisation avec captures d'écran
   - APK mobile
   - Suivi des tâches
   - Gestion des aléas
3. Membres de l'équipe:
   - Nom, prénom et Numéro ETU de chaque membre
